# ✨ Parajuli Fabric Store (पराजुली फेब्रिक स्टोर)

> **Luxury Fabrics & Haute Couture Atelier — Zero Km, Pokhara-5, Nepal**  
> *Handcrafted for discerning fabric lovers, offering heirloom Banarasi silk sharees, pure Himalayan cashmere pashmina, Italian suiting, and bespoke tailoring materials.*

---

## 🌟 Key Features

- 🇳🇵 **Instant Bilingual Support**: Seamless header toggle between English and Nepali (नेपाली), with full translation across all products, calculators, store notices, and chatbot.
- 👘 **Curated Textile Catalog**:
  - **Exquisite Sharees**: Handwoven Katan Silk Banarasi, Tissue Organza, and Chanderi.
  - **Fabrics in Meter-wise**: 100% Himalayan Cashmere Pashmina, Raw Slub Silk, and Belgian Linen.
  - **Readymade Garments**: Designer Kurtha sets, Palpali Dhaka fusion waistcoats, and Kalidar Anarkalis.
  - **Suiting & Shirting**: Italian Super 140s Merino Wool, Egyptian Giza Cotton, and Nepali Daura Suruwal Wool.
- 📐 **Interactive Fabric Meter Calculator**: Customer tool for selecting garment types and fits (Classic, Slim, Flared) to calculate exact meter requirements and pre-fill WhatsApp orders.
- 📍 **Drive-to-Store Sales Hub**: Dedicated Zero Km showroom showcase with directions from Lakeside (8–10 min), Prithvi Chowk, and an interactive embedded Google Map.
- 💬 **Parajuli Style Assistant**: Sleek floating chatbot with pre-scripted interactive options in English and Nepali, plus direct WhatsApp stylist escalation.
- 🟢 **Direct WhatsApp Integration**: Instant 1-click inquiries to `+977 9856025496` with pre-filled product titles and specifications.

## 🛠️ Technology Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React + Custom WhatsApp Brand Component
- **Typography**: Cormorant Garamond, Plus Jakarta Sans, and Mukta (Devanagari)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Nepsys60/prajuli-shop.git
cd prajuli-shop
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5188](http://localhost:5188) in your browser.

### 4. Build for production
```bash
npm run build
```
